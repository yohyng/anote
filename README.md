# Pencil Room

Graph / Entra なしの Share PNG 版です。

## 使い方

```bash
npm install
npm run dev
```

## Vercel

- Framework Preset: Vite
- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: `dist`

## 想定フロー

Androidで手書き・画像貼り込み → Share PNG → OneDriveの `/PencilRoom/inbox` へ保存 → PC側でPPTXへ追加。
